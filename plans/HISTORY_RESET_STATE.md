# History reset — state of record & restore procedure

**Status: PARKED as-is (2026-07-25, owner decision).** Development continues normally on top
of the current history. This document records exactly how the reset was left, how to
*complete* it later, and how to *fully restore* the old history — so either path stays open

## What happened

On **2026-07-18**, alongside the relicense to the ReactiveUI Community License 1.0 (see
`LICENSE`, first carried by v0.12.0), the repository's public history was reset: `master`
was replaced with a single orphan root commit whose tree is byte-identical to the final
pre-reset commit, and the old branches, tags, and releases were removed. The pre-reset
history (446 commits dating to 2026-06-20) contained code distributed under earlier
licenses; the reset removed it from casual public access. Complete private backups were
taken first — nothing is lost.

## Path B — full restore of the old history

From the mirror (or the Drive zip, unzipped). Restores every branch and tag with identical
SHAs; PR pages re-light automatically since the objects were never gc'd:

```bash
cd C:/Yanivs/GameDev/ReactiveUI/blackout-backups/2026-07-18/ReactiveUI-Godot.git
# 1. All branches (force — overwrites master/dev; repo-admin ruleset bypass carries it)

# 2. All 209 old tags (the v0.12.0-wave tags are untouched; no name collisions)
git push https://github.com/yanivkalfa/ReactiveUI-Godot.git "refs/tags/*:refs/tags/*"
```
